第01回 授業時間外学習（宿題）チェックシート

次回の授業までに取り組むタスク一覧

次回講義冒頭で小テストが実施されます。第01回の「定着確認」問題・解答を繰り返し確認しておきましょう。
教科書 pp.15-19「1-1 データベースとは何か」を読んでおきましょう（想定時間: 約20分）。
講義資料を熟読し、理解が曖昧な用語はWeb検索やChatGPTなどの生成AIを活用して解消してください。
特に資料内の (プロンプト例) を生成AIに入力し、対話しながら知識を深めましょう。
講義資料内の「演習」（DB Fiddleを使用したSQL実行）に再度取り組み、構文や結果の動きを体感しておきましょう。
Docker Desktopを導入し、ターミナルで以下の動作確認コマンドを実行しておきましょう。
docker run --rm hello-world
容量が大きいため学校ではなく自宅環境等の回線で以下を実行してください。
docker image pull postgres:18.6
docker image pull dbgate/dbgate:7.2.6
実行後、docker images で一覧に表示されるか確認します。

環境構築や課題で問題が発生した場合は、遅くとも講義の前日までにアポをとって教員に相談してください。
